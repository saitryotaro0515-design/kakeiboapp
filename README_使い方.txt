家計ラボ v1.0 — iPhone / Mac 向け家計・収支管理アプリ
============================================

【できること】
・日々の収支の記録・編集・削除（利用日・引落日を別々に登録できます）
・日付別の収入・支出・差額の集計
・週次の支出推移、直近4週間の週平均、過去7日間の1日平均
・月次の費目別分析・予算管理
・過去の月平均と現在の支出ペースから、月末の支出を予測
・給与や賞与、旅行などの予定を含めて年間余剰資金を予測
・JSONバックアップの保存・復元、明細CSVの出力・取込
・Mac、iPhone、iPadに対応（スマホ向け画面・ホーム画面追加）

【重要：AWSなどのバックエンドは使用しません】
HTML / CSS / JavaScript だけで動きます。取引明細は利用端末のブラウザ内に保存され、サーバーには送信しません。
外部ライブラリ・広告・トラッキング・ログイン機能はありません。
ただし、iPhoneのホーム画面に「アプリ」として追加する場合は、PWA用のファイルをHTTPSで配信する必要があります。
GitHub Pagesのような無料の静的サイト配信を使えます。ここにアップロードするのはアプリのプログラムだけです。

【Macですぐに試す】
別添の「家計ラボ_Macですぐ開く.html」をMacでダウンロードしてダブルクリックして開きます。
Safariでうまく開かない場合は右クリック →「このアプリケーションで開く」→ Chrome / Safari を選びます。
Macで継続利用するときも、下記のHTTPS版の同じURLから開く方が動作とデータ保存が安定します。

【iPhoneで使う（無料のGitHub Pages例）】
1. GitHub（https://github.com/）にログインし、新しい公開リポジトリを作ります。
2. このZIPを解凍し、中の index.html / styles.css / app.js / sw.js / manifest.webmanifest /
   icon-192.png / icon-512.png をリポジトリの最上位にアップロードします。
   ※READMEは任意。JSONバックアップやCSVの家計データは絶対にアップロードしないでください。
3. リポジトリの「Settings」→「Pages」→「Build and deployment」で
   「Deploy from a branch」を選択し、「main」「/(root)」を選んで保存します。
4. Pagesに表示される https://（ユーザー名）.github.io/（リポジトリ名）/ をiPhoneのSafariで開きます。
5. Safariの共有メニュー →「ホーム画面に追加」を選びます。
6. 以後はホーム画面の「家計ラボ」から開けます。一度オンラインで開いてアプリのファイルがキャッシュされるとオフラインでも使えます。

【最初に設定しておくと便利なこと】
設定 →「基本設定」で見込手取り月収（未記録月に使う）と目標額を入力。
設定 →「カテゴリー」で食費・趣味などの「月の見込額」「月予算」を入力。
「月の見込額」が0円なら過去の支出平均から推測します。
少なくとも3か月分ほど記録があると月次の予測に役立ちます。
「設定」→「データ管理」→「サンプルデータを入れる」で架空の履歴を試せます。

【計算の基本】
週平均（直近4週）＝終了した4週間の支出合計 ÷ 4
過去7日の1日平均＝直近7日間の支出 ÷ 7
カテゴリー月平均＝直近N個の完了月の支出平均（記録開始前の月は除外）
今月の変動費の予測＝当月実績＋残日数×（過去月平均と今月1日当たり実績を加重した額）
月の余剰予測＝月の予測収入 − 月の予測支出
年の余剰予測＝12か月の余剰予測の合計（予定の賞与・特別支出も反映）
※収支の集計は「利用日」基準です。「引落日」は別記録・支払月別確認に使用します。
※貯金口座への振替やNISA積立は「資金移動」として登録すれば支出に二重計上されません。
※予定を実際の明細として記録したら、「実績反映済み」に変更してください。
※年の余剰は「純粋な収入－支出」の予測であり、預金残高や資産総額ではありません。

【データの安全管理】
・データは端末とブラウザ単位で独立しています（iPhoneとMacの自動同期はありません）。
・ブラウザのサイトデータ削除、端末の故障、ストレージ整理などで消えることがあります。
・定期的に設定 → データ管理 →「JSONを保存」からバックアップしてください。
・別の端末に移す場合はJSONファイルを渡して「JSONから復元」を使用します。
・バックアップファイルには金額などの個人情報が含まれるので、公開リポジトリ等にアップロードしないでください。
